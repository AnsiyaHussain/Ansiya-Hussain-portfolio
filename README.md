# Ansiya K H — Portfolio

Modern React/Vite portfolio with Framer Motion and a lightweight React Three Fiber hero scene.

## Run
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```

## Customize
- Personal/project content: `src/data.js` and `src/App.jsx`
- Theme/layout: `src/styles.css`
- 3D hero: `src/components/Scene.jsx`
- Add the real CV as `public/Ansiya-K-H-CV.pdf`
- Replace placeholder LinkedIn/GitHub URLs in `src/App.jsx` with the real profile URLs.

The contact form is UI-only by default. Connect it to Formspree, EmailJS, your Django API, or another backend before deployment.
